## Upload ke GitHub
Upload 4 file ini ke root repository:
- index.html
- admin.html
- style.css
- app.js

Lalu GitHub:
Settings > Pages > Deploy from a branch > main > /root > Save

Halaman publik:
https://USERNAME.github.io/NAMA-REPO/

Admin:
https://USERNAME.github.io/NAMA-REPO/admin.html

Login admin memakai email + password yang sudah dibuat di Supabase Authentication.

Batas:
- gambar maksimal 5 MB
- video maksimal 50 MB

Penting:
Publishable key boleh berada di frontend. Jangan pernah memasukkan secret key atau service_role key ke GitHub.
